# Does quick-fix stay separate?

## Question

`/spechub:quick-fix` is the most-used skill in the set. Does it become a small
map, or stay outside the graph?

## Answer

Stays exactly as it is. Never creates a node.

Broken is a different axis from foggy. A bug has a root cause to find, not a
decision to settle, so the machinery a map provides – frontier, blocking edges,
provenance – buys nothing. Folding it in would be the same mistake as tiers:
imposing structure where the work does not have that shape.
